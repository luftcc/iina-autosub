# iina-autosub 详细使用指南

本指南帮助你从零安装、实时查看字幕生成进度、灵活切换本地/云端模型，以及解决常见问题。

---

## 一、安装与首次启用

### 1. 一键安装
```bash
git clone https://github.com/luftcc/iina-autosub.git
cd iina-autosub
./install.sh
```
> 若你处于中国大陆网络且**未开启**全局/系统代理，推荐执行 `./install.sh --hf-mirror`。  
> 若你已开启 Clash / Surge 等 macOS 系统代理，引擎会自动识别系统代理，无需额外配置。

安装脚本会自动完成：
1. 自动安装独立 `uv` 与隔离的 Python 3.12 环境（不污染系统环境）；
2. 自动准备 Apple Silicon 静态版 `ffmpeg/ffprobe` 与轻量 `Silero VAD` 模型（~2 MB）；
3. 注册 macOS 后台服务 `LaunchAgent`（监听 `127.0.0.1:18421`，空闲时仅占 ~40 MB 内存）；
4. 将插件安装到 IINA 插件目录，并在 `dist/iina-autosub.iinaplgz` 生成可分发的插件包。

### 2. 在 IINA 中启用插件（仅首次）
1. 打开 **IINA → 设置 (`⌘,`) → 插件**；
2. 如果顶部未开启插件系统，勾选 **「启用插件系统」** 并重启 IINA；
3. 在插件列表中勾选启用 **「AutoSub AI 字幕」**（也可直接双击 `dist/iina-autosub.iinaplgz` 弹窗安装）；
4. 在 **IINA → 设置 → 字幕 → 自动加载** 中保持默认的 **「由 IINA 智能检测」** 或 **「包含媒体文件名」**。

## 二、打开电影并查看实时进度（3 种方式）

打开一部没有中文字幕的本地日本电影后，插件默认会自动检测并开始一次性生成全片字幕（若希望改为手动触发，可在插件设置中取消勾选「自动开始」）。

### 方式 1：IINA「AI 字幕控制面板」独立窗口（最推荐）
- 任务开始时会自动弹出 **「AI 字幕控制面板」** 窗口（也可随时按 **`⌘⇧A`** 或菜单栏 **插件 → AutoSub AI 字幕 → 打开 AI 字幕面板** 呼出）。
- *(注：IINA 1.4.2 内置侧栏 `sidebar.loadFile` 在新版 macOS WebKit 下存在已知空白问题 `iina/plugin-opensub#4`，因此本插件默认使用 IINA 原生 `standaloneWindow` 独立面板呈现，稳定无白屏。)*
- 面板实时展示：
  - **5 步流水线状态灯**：`音轨` → `人声` → `识别` → `翻译` → `加载`
  - **实时百分比进度条 + 已用时长（`01:24`）**
  - **当前详细状态**（例如：`首次下载模型 Qwen3-14B-4bit (48% · 4.02/8.31 GB · 7.2 MB/s)`、`语音识别中 (12/45 段)`、`本地翻译中 (8/22 批)`）
  - 一键 **「取消当前任务」** 按钮

### 方式 2：浏览器实时状态监控页（适合后台看大电影）
- 在控制面板点击 **「在浏览器打开实时状态页」**，或直接打开：
  **`http://127.0.0.1:18421`**
- 可查看所有运行中/历史任务的进度、耗时、输出字幕路径，以及本机所有模型哪些已缓存（`✅ 已缓存`）。

### 方式 3：画面 OSD 轻提示
- 每个阶段切换以及长任务进行中，IINA 画面左上角会定期轻提示当前百分比与阶段；生成完成后自动通过 `sub-add` 热加载到当前画面并提示「AI 字幕已加载」。

> **首次运行耗时说明**：  
> - **首次使用某个新模型时**，需要先从 Hugging Face 下载一次权重（Whisper 约 1.6 GB，本地翻译模型 4.4 GB ~ 18 GB 不等），下载完成后会永久缓存在 `~/.cache/huggingface/hub/`；  
> - **模型已缓存后（日常观影）**：一部 2 小时日本电影在 Apple Silicon 上通常仅需几分钟即可一次性跑完并生成同目录 `.zh-ja.ass`，以后每次再打开该电影都会直接秒加载，无需重复生成。

## 三、如何切换模型（本地离线 / 云端 API）

你可以通过 **AI 字幕控制面板快捷切换（最方便）** 或 **IINA 插件偏好设置（完整配置）** 切换模型。

### 方式 A：在「AI 字幕控制面板」直接切换（推荐）
按 **`⌘⇧A`**（或菜单栏 **插件 → AutoSub AI 字幕 → 打开 AI 字幕面板**）呼出控制面板：
1. **切换日语语音识别模型（ASR）**：在「日语语音识别模型」下拉框直接选择：
   - `Whisper Large v3 Turbo`（~1.6 GB，默认均衡，词级时间轴稳，兼容片中偶发英文）
   - `Whisper Large v3 Turbo 4-bit`（~0.5 GB，最省内存、下载最快）
   - `Kotoba Whisper v2.1`（~1.5 GB，纯日语语料微调，纯日剧/日本电影识别字错率更低）
2. **切换翻译引擎**：点击 **`本地离线 (免费)`** 或 **`云端 API`** 按钮。
3. **切换本地翻译模型（本地离线模式）**：在「本地翻译模型」下拉框直接选择（每个选项都会实时标注 **`✅ 已缓存`** 或下载体积）：
   - `自动推荐`（16GB→7B / 24–36GB→8B / 48GB+→14B）
   - `轻量 7B (Qwen2.5-7B-4bit)`（~4.4 GB，速度最快，适合 16GB Mac）
   - `均衡 8B (Qwen3-8B-4bit)`（~4.7 GB，速度与质量均衡）
   - `高质 14B (Qwen3-14B-4bit)`（~8.3 GB，上下文与长句表现优秀，推荐 24GB+ Mac）
   - `旗舰 32B (Qwen3-32B-4bit)`（~18.4 GB，接近云端旗舰观感，推荐 64GB/128GB Mac）

> **提示**：切换模型后，对**下一次**生成生效；若当前影片已经生成过一次，点击侧边栏的 **「强制重新生成」** 会**自动复用语音识别缓存（跳过 Whisper）**，直接用新选的翻译模型重新翻译，非常快！

### 方式 B：在 IINA 插件偏好设置中进行高级配置
路径：**IINA → 设置 (`⌘,`) → 插件 → AutoSub AI 字幕 → 偏好设置**

#### 1. 使用自定义本地 MLX 模型（如 Sakura-LLM）
在 **「自定义本地 MLX 模型」** 输入框中填入任意 Hugging Face MLX 仓库名（或本机模型目录绝对路径），留空则恢复使用上方预设档位。

#### 2. 配置云端大模型 API（支持所有 OpenAI 兼容接口）
将翻译模式选为 **「云端大模型 API」**，然后填写三项即可（修改完关闭设置窗口自动保存）：

| 服务商 | Cloud Base URL | Cloud Model 示例 |
| :--- | :--- | :--- |
| **DeepSeek** | `https://api.deepseek.com/v1` | `deepseek-chat` |
| **OpenAI** | `https://api.openai.com/v1` | `gpt-4o-mini` / `gpt-4.1-mini` |
| **Gemini (OpenAI 兼容)** | `https://generativelanguage.googleapis.com/v1beta/openai/` | `gemini-2.5-flash` |
| **本地 Ollama** | `http://127.0.0.1:11434/v1` | `qwen2.5:14b` |

> **安全说明**：你填写的 `API Key` 只保存在你本机 IINA 的本地偏好存储中，不会上传到任何第三方服务器，也完全位于本代码仓库之外。

## 四、实用功能与快捷键

| 快捷键 / 入口 | 功能 |
| :--- | :--- |
| `⌘⇧S` | 一键为当前电影生成中文字幕 |
| `⌘⇧A` | 打开/聚焦右侧「AI 字幕」面板（查看进度、选音轨、切模型） |
| 侧边栏「日语源音轨」 | 多音轨 MKV 可手动指定日语原声轨（默认自动避开导演评论轨） |
| 侧边栏「中日双语 / 纯简体中文」 | 默认输出 `<电影名>.zh-ja.ass`（上方 `PingFang SC` 简体中文 + 下方 `Hiragino Sans` 日文），可切纯中 `.zh-Hans.ass` 或在偏好中切 `.srt` |
| 内嵌日语字幕直译 | 若 MKV 已自带日语软字幕，默认自动提取直接翻译（跳过语音识别，几十秒完成） |
| 断点与 ASR 缓存 | 每部电影的日语识别结果会缓存在 `~/.cache/iina-autosub/asr_cache/`；换模型重翻不用重跑语音识别 |

## 五、常见问题排查

1. **面板显示「引擎未连接」？**
   - 点击侧边栏的 **「唤醒本地引擎」** 按钮；
   - 或在终端执行 `./engine/.venv/bin/iina-autosub doctor` 检查环境，查看日志：`tail -f ~/Library/Logs/iina-autosub/engine.err.log`。
2. **首次下载模型卡住或很慢？**
   - 如果开了 Clash/Surge 等系统代理，引擎会自动走系统代理；
   - 如果没开代理，前往插件偏好设置勾选 **「使用 Hugging Face 国内镜像源 (`hf-mirror.com`)」** 后重试；
   - 也可在侧边栏改选更小体积的 `均衡 8B`（~4.7 GB）或 `轻量 7B`（~4.4 GB）。
3. **打开电影后没有自动触发？**
   - 检查影片是否已经内嵌了中文字幕，或同目录下已存在 `.zh*.ass/.srt`（检测到已有中字时会自动跳过）；
   - 网络在线流（`http://`/`https://`）会自动跳过，仅对本地文件生效；
   - 如想强制重新生成，点击侧边栏 **「强制重新生成」** 即可。
4. **移动了项目目录怎么办？**
   - 移动文件夹后，在新目录重新运行一次 `./install.sh` 即可自动更新 `LaunchAgent` 路径。
5. **如何彻底卸载？**
   ```bash
   ./uninstall.sh                 # 移除后台服务、IINA 插件与虚拟环境（保留模型缓存）
   ./uninstall.sh --purge-cache   # 同时清空 VAD 与 ASR 缓存
   ```
   *(Hugging Face 模型权重位于 `~/.cache/huggingface/hub/`，如需释放磁盘空间可按需手动清理对应模型目录。)*
